# Hi.
This is a browser extension which works on Chrome, Edge, Brave, Opera, Vivaldi, Firefox, Safari.
It enhances the discord experience by providing an improved interface, be it seeing deleted messages highlighted red, original edited messages, convenient status check, and more.
## Installation processes vary for every browser extension, so please read the instructions below for the installation guide.
Instructions are below.

# Installation Instructions:
**Chrome, Microsoft Edge, Brave, Opera, Vivaldi:**
Click the green code button on the repository homepage, and select “Download as ZIP”. Unzip the file, then navigate to your designated browser and select the ‘Extensions’ tab. Search *WebsiteName://extensions* (<—- Replace WebsiteName with your designated website. for Microsoft Edge, it’s simply ‘edge’).
Turn on developer mode using the toggle in the top-right corner, click Load Unpacked, and select the discord-extension folder from inside the unzipped download. The extension activates **immediately** when you open discord, and is a permanent change. 

**Firefox**:
Unzip the file the same way as the previous few websites.
Unfortunately, for Firefox, there is no way I can permanently make this extension last, as it refreshes every time the browser is closed. You’re better off switching to other websites.
But if you genuinely want to stay with it, then a temporary option is to go to about:debugging#/runtime/this-firefox and select the manifest.json file inside the discord-extension folder. It’ll work until you close the website, at which point you have to re-install it.

**Safari**:
If you’re on anything other than a Mac, forget it. It isn’t going to work.
For Mac users, you’ll need to download Xcode (which is free on App Store), download and unzip the zip file, open terminal (CMD+spacebar, type terminal, press enter), run ‘xcrun safari-web-extension-converter‘ pointing at the discord-extension folder, press CMD+R to build, then go to Safari settings and then extensions, and finally click on the Discord Enhancer from the list.

I would recommend you just switch to Safari or other alternatives. if you are on Firefox. There’s nothing I can really do for Firefox right now to keep the extension running. Mozilla is a different story and is much more complex, and I also wouldn’t recommend that.
